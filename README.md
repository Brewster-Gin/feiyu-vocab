# 肥鱼背单词

> 一个会“盯着你”的 Windows 桌面背单词工具：开机、解锁、每天固定时间自动弹窗，拼写测试全对才算打卡。

不依赖任何在线服务，词库和计划全在本地。

## 它解决什么问题

自制力不够的人，单词软件最大的问题是**可以随时关掉**。这个工具把门槛做硬了：

- 每天到点自动弹出来，躲不掉；
- 打卡前必须先做拼写测试，**全对才通过**，错 3 次当轮作废；
- 通过了才写进 Excel 打卡表，绿格子和连续天数就是你的进度。

## 功能

| 功能 | 说明 |
|---|---|
| 自动提醒 | 登录系统 / 解锁屏幕 / 每天 20:30 三处触发，已完成或已跳过的当天不再打扰 |
| 每日计划 | 每天 10 个新词 + 第 1/4/15 天滚动复习，单日封顶 40 词 |
| 拼写测试 | 中文给义，默写英文；错 1 次重试、错 2 次给首字母、错 3 次作废 |
| 打卡表 | 自动写入 Excel：每日打卡 / 单词总表 / 统计三个工作表 |
| 可切换词库 | 内置词库 + 自建词库，CSV 一行一个词，随时切换 |
| 暂停 | 暂停 1/3/7 天或长期，**计划一起冻结**，恢复后整体顺延 |
| 跳过与撤销 | 当天跳过会二次确认，事后可在弹窗里一键撤销 |
| 目标倒计时 | 目标日期和名称都能自己改，也可以完全关掉 |
| 无控制台黑框 | 全程通过 `wscript` 隐藏启动 |

## 安装

两个包内容一样，任选其一：

| 文件 | 说明 |
|---|---|
| `肥鱼背单词-安装包.exe` | 双击即装。无签名，首次运行需点「更多信息 → 仍要运行」 |
| `肥鱼背单词-安装包.zip` | 解压后双击 `安装.cmd`，不触发 SmartScreen |

安装时可自选路径（默认 `%LOCALAPPDATA%\CET6Plan`）。有管理员权限会注册计划任务（登录/解锁/20:30）；没有也能用，退化成「启动文件夹」方式（只有登录提醒）。

安装后会有：

- 桌面图标「肥鱼背单词」
- 开始菜单「肥鱼背单词」→ 打开 / 卸载

## 每天怎么用

1. 弹窗出现，看到今天的 10 个新词 + 复习组
2. 背完点「今天已完成」
3. 拼写测试，全对通过
4. 自动打卡，弹窗关闭

其他按钮：

- **10 分钟后再提醒** — 临时推迟
- **打开打卡表** — 直接打开 Excel
- **今天跳过** — 二次确认后跳过，当天不再弹
- **词**（右上角）— 切换/添加词库
- **II**（右上角）— 暂停，连计划一起冻结
- **点标题下的日期** — 设置目标日期与名称

## 词库格式

放进 `词库/` 目录即可，一个 CSV 一个词库：

```csv
word,pos,meaning,phrase,ipa
abandon,v.,放弃；抛弃,abandon the plan,/əˈbændən/
```

- 必需：`word`（单词）、`meaning`（释义）
- 可选：`pos` 词性、`phrase` 搭配、`ipa` 音标
- 也支持 `.txt`，每行一个词：`abandon /əˈbændən/ 放弃；抛弃`

在弹窗里点「词」→「添加词库…」，或双击 `词库管理.cmd` 用命令行批量导入。

## 从源码构建

需要 Python 3（仅构建时需要，日常运行不需要）：

```bash
# 重新排计划 / 换词库
python 工具/build_plan.py --deck "词库/六级核心400.csv" --per-day 10 --intervals 1,4,15 --start 2026-11-02 --exam 2026-12-12

# 重新打安装包（Windows 自带 IExpress）
python 工具/build_installer.py
```

## 常见问题

**双击 exe 提示「Windows 已保护你的电脑」？**
程序没有购买代码签名证书，这是正常现象。点「更多信息 → 仍要运行」即可；不放心就改用 zip 版。

**开机没有自动弹出？**
安装时如果没给管理员权限，只会注册「登录提醒」。重新以管理员身份运行 `安装.cmd` 可获得登录 / 解锁 / 20:30 三个触发时机。

**卸载在哪里？**
开始菜单 →「肥鱼背单词」→「卸载肥鱼背单词」；或运行安装目录下的 `uninstall-all.ps1`。

**移动了程序文件夹后不弹了？**
快捷方式和计划任务里存的是绝对路径。运行 `移动后修复.cmd` 会自动重建。

**改了代码要重新打包吗？**
要。`python 工具/build_installer.py` 会重新生成单文件安装包。
